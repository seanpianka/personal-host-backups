Personal use

Mac Mini Backup is a utility operated by its owner for personal backups. It is not offered as a service to other users. The owner controls which files are backed up and the Google account used for storage.

Operating limits

Successful backups depend on source-file availability, valid Google authorization, network connectivity, available storage and Google API limits. Local and cloud retention can remove files. The owner should verify backup status and retain any files that need longer preservation.

No availability guarantee

The utility is provided as is, without a guarantee of continuous operation, complete backup coverage or recovery of deleted files. It should not be the sole copy of irreplaceable data.
